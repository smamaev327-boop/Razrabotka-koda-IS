# Razrabotka-koda-IS
Учет товаров в продуктовом магазине
Язык: Python 
Библиотека для интерфейса: tkinter
База данных: MySQL
IDE: VS Code (Visual Studio Code) + mysql-connector-python
Наброски ИС:
- учёт товаров
- ко-во товаров
- сроки годности
- наличие товаров 
- привоз товаров 
- роли: Админ, консультант
